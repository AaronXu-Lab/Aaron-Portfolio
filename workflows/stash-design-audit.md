# 暂存箱文案与信息密度审计

## 1. 任务与状态

2026-09-07，对当前工作区及本地 `/tools/stash/` 实际界面审计，已包含 Markdown 编辑器。旧版 textarea 截图不作为当前证据。用户任务：直接编辑、复制文字，存放或下载唯一文件，查看自动清空时间。桌面鼠标键盘与手机触控，浅色独立工具页。当前可见状态为已有文字、无文件；空箱、文件存在、保存中、失败与加载状态由当前源码确认，实施后用本地接口复核。无账号或权限等级；多文件为不支持状态。生产内容不用于写入测试。

## 2. 当前状态盘点

- 顶栏：装饰图标、「一个公共的小箱子」、清空箱子。
- 页头：带句号的暂存箱标题、用途说明、「所有人共用，随手存取」。
- 文字区：文字标签、复制按钮、Markdown 编辑器、连接/保存状态、常驻自动保存说明。
- 文件区：数量与大小限制、装饰箭头、空状态/文件名、辅助文案、上传/替换、下载、移除、上传进度。
- 页脚：绿色圆点、下次清空时间、保留规则、公共可见性与内容提示。
- 错误：独立 alert；同时会改写文字区状态。
- 来源：「造物」的暂存箱卡片提供名称、用途、限制和公共属性，进入工具后应维持识别，不能据此删除工具自身的必要说明。

## 4. 决策表

| 决策 | 对象 | 理由 |
| --- | --- | --- |
| 删除 | 顶栏图标与别称、页头公共副标、页脚圆点、文件装饰箭头 | 身份/公共属性重复，图形不承担动作或状态语义 |
| 合并 | 页头标题与清空按钮；自动保存与状态 | 单一身份层，单一保存状态来源 |
| 移动 | 完整公共访问说明到编辑器之前 | 输入前即可理解内容可见性，只保留一处 |

| 保留 | Markdown 原文、7 天规则、具体时间、数量与大小限制、局部操作 | 都直接支持存取或判断，不为减高度删除 |
| 拆分 | 错误标题与恢复说明 | 标题点名对象与动作，描述给出下一步；不再另报泛化失败 |
| 缩短 | 长文件名的中间部分 | 保留首部和扩展名，完整名称可通过 title 与无障碍名称读取 |

## 5. 标准信息层级

页头：暂存箱 + 清空箱子 → 一句跨设备用途 → 一处公共访问说明。主区域：文字 + 复制 → 编辑器 → 唯一保存状态；文件 + 限制 → 文件名/空态、大小/拖放说明 → 下载、移除、上传/替换。页脚：有内容时显示清空时间，始终显示「最后修改 7 天后自动清空」。异常时出现一个失败与恢复单元。

## 6. 已验证缺口 / 非缺口

已验证缺口：上传失败也把文字保存状态改成泛化失败；正常轮询会覆盖错误，导致未完成操作的恢复指引消失；文件大小 KB 档保留小数不符合 H2；长文件名可无限撑高文件区域。以上只修展示与反馈，不改 API 契约。

非缺口：无须增加公开徽章、额外保存按钮、Markdown 预览页、二次覆盖确认、历史版本、更多安全提示。日期已格式化，并非原始时间戳直传。

时间格式待处理：`src/lib/stash/app.js:17` 的 Intl 输出包含同年年份与秒，与 D1/D2 契约不同。本轮不复制 Skill 的时间库；保留现有准确时间，单独登记，避免扩大接入范围。项目禁止孤立「—」，不执行 D5 的空值字符替换；空箱没有下一次清空时间，整行不适用而非缺失值。

## 7. 不建议做什么

不增加公共徽标、帮助折叠页、确认弹窗、保存按钮、复制成功 toast；不把清空时间替换为仅有颜色的状态；不删除文件限制、失败恢复或公共可见性信息；不调整 Markdown 规则与存储期限。
