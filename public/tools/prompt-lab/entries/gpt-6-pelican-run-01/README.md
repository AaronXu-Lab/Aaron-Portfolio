# 海风骑行 · Pelican Island

作品 ID：`gpt-6-pelican-run-01`。Prompt 版本：`pelican-v1`。

实时 Three.js 微缩海岛，全部角色、车辆与环境使用程序化三维几何建模。运行时没有外部资源、在线字体或 API。仅图标使用随作品保存的 Phosphor SVG。

## 操作

- 自动以 8 km/h 巡航；长按「长按加速」提升至 23 km/h，松开后平滑回落。
- 单指拖动旋转视角，双指缩放；桌面可以拖动和滚轮缩放。
- 「跃起」执行起跳与落地，「车铃」产生可见反馈和用户触发的合成铃声。
- 右侧按钮切换跟随与环岛视角、恢复默认构图；顶部切换昼夜、暂停与继续。
- 每圈可收集 8 条鱼。速度、圈数和鱼数来自场景实际状态。
- 键盘：Space / P 暂停或继续，↑ / W 长按加速，J 跃起，B 车铃，V 切换视角，N 切换昼夜，R 重置视角，← / → 旋转，+ / - 缩放，H / ? 打开快捷键说明。
- 先点击场景或用 Tab 聚焦控件。按钮聚焦时保留 Space / Enter 原生操作；Esc 关闭说明。其他快捷键在按钮聚焦后仍然生效。
- 按住键时不重复触发暂停、车铃等单次操作；切走窗口、打开说明或页面进入后台会释放加速。

## 动画与性能

双腿采用两段骨骼逆向运动学，脚掌持续跟随曲柄上的踏板。车轮滚动对应真实路程，踩踏频率随速度平滑变化。围巾变形、棕榈摇摆、海面波动、海鸥飞行和夜间灯塔光束使用实时动画。开启系统减少动态效果时默认暂停自动骑行，并停用环境循环与收鱼粒子，仍允许主动骑行与操作视角。

静态岛屿、车架、轮辐和羽毛按材质合并网格，保留需要独立运动的节点。像素比上限为 1.8，阴影贴图为 1024px。手机帧率仍需真机实测。
