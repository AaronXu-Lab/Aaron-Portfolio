# 落日邮差 · Pelican Post

Prompt 擂台独立作品：`gpt-6-astra-pelican-run-01`。登记显示名为用户指定的 **GPT-6 Astra · High**，准确模型快照未提供。

## 实现

- 原生 ES modules + 本地 Three.js r185；没有运行时 CDN、外部 API、在线字体、图片或视频。
- 鹈鹕、自行车、海岸、灯塔、帆船和信件均为实时 3D 几何体。羽翼以肩关节展开，双腿通过双节逆运动学跟随曲柄；轮转与行进距离对应。
- 指针捕获支持按住加速，同时可用第二根手指跳跃；拖动场景旋转相机。松手、取消触摸、失焦和页面隐藏都会解除加速。
- 漂浮信件有高低两种位置；每收齐八封信进入下一趟。无死亡、计时或惩罚。
- 昼夜切换、合成铃声、三个预设相机角度、暂停和重来。声音默认关闭，用户开启后才创建音频上下文。
- 减少动态效果偏好默认暂停，并关闭环境摆动、身体摇摆等辅助动效。用户仍可主动开始骑行。
- 使用展示台既有 service worker。联网完整访问并缓存后可离线运行；作品不修改父页面或缓存策略。

## 操作

| 操作 | 触控 | 键盘 |
| --- | --- | --- |
| 加速 | 按住「骑行」 | 按住 W / ↑ |
| 跳跃 | 点「跃起」 | Space |
| 响铃 | 点「叮铃」 | B |
| 昼夜 | 月亮 / 太阳按钮 | N |
| 预设视角 | 相机按钮 | C |
| 旋转视角 | 单指拖动场景 | ← / → |
| 声音 | 扬声器按钮 | M |
| 暂停 | 暂停按钮 | P |
| 重来 | 点「重来」 | R |
| 帮助 | 问号按钮 | H；Escape 关闭 |

Space 在按钮获得焦点时保留原生按钮激活行为。
