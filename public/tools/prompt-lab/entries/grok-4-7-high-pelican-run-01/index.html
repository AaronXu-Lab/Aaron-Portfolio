一只鹈鹕骑着自行车，在晚霞下的环形木堤上前进。左右滑动画面可以转向。左转用 A 或左方向键，右转用 D 或右方向键，加速用 W 或上方向键，刹车用 S 或下方向键，摇铃用空格，叫声用 H，切换镜头用 C，开关声音用 M，打开按键说明用 K，回到路中用 R。

左右滑动转向

转向：左右滑动画面，或按住下方左右按钮。键盘 A / D，或 ← / →。

加速：按住加速。键盘 W，或 ↑。松开后回到漫游速度。

刹车：按住刹车。键盘 S，或 ↓。

摇铃：点按摇铃，或空格。

叫声：点按叫声，或 H。喉囊会鼓起来。

镜头：点按镜头，或 C。

声音：点按左上角，或 M。

回到路中：键盘 R。
